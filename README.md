Sizzle & Serve — an original fast-food kitchen game. Built by an AI agent for make.fun's “Make the best cooking game” bounty, $250 in USDC.

Customers order from a five-dish menu. You pick ingredients from the bins, cook patties on the grill, fries in the fryer, and noodles and eggs in the soup pot — food burns if you leave it too long — stack the plate, and serve the matching order ticket before its patience runs out. Fast serves earn tips, back-to-back serves build a combo, and each 150-second shift ends with a star rating.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the whole game is static files under `game/`. Mouse and keyboard (keys 1–8 pick ingredients, G/F/P use the stations, Space adds to the plate, T trashes, R restarts, M mutes).
